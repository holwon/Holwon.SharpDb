# 05: 描述表（SQLite）

**What to build:** AI 能问"这张表长什么样"，拿到完整的结构：列（名称 / 序号 / 声明类型 / 可空 / 默认值 / 自增 / 注释）、主键、外键、索引。有了它，AI 才能写出正确的连接与查询，而不是靠猜。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] SQLite Provider 实现描述表的能力，把 04 定型的 Schema 聚合**填满**
- [ ] `describe_table` 工具返回聚合根的单对象形态：名称、类型、可选注释、列数组、主键、外键数组、索引数组
- [ ] 主键是**有序列名数组**；`indexes` **不重复包含主键**
- [ ] 外键含：名称、本地列、被引用的表与列、删除动作、更新动作（动作序列化为枚举名）
- [ ] 空值字段省略，不输出 `null`
- [ ] 自增由 Provider **计算**得出（主键 + 整型声明类型），不是直接读某个字段
- [ ] 外键指向父表主键而 SQLite 未显式记录列时，被引用列可为空列表且不报错
- [ ] 表不存在时返回错误结果（`IsError`），带明确的"表不存在"消息
- [ ] 视图也能被描述

---

**验收说明**：断言"这张表长什么样"（列序、类型字符串、主键序、外键与索引内容），**不断言**内省 SQL 文本。测试要覆盖：有外键与索引的表、无外键的表、空默认值与有默认值、视图、不存在的表。

# 04: PostgreSQL `describe_table`：外键、索引与注释

**What to build:**

同一张表的描述补齐其余部分：外键（含复合键的**本地列与引用列逐步配对**，以及 `ON DELETE` / `ON UPDATE` 动作）、索引（含列清单与唯一性，且**主键背后的索引不重复出现**）、以及表与列的注释。描述一个视图时，只给列，不给键、外键或索引。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 外键报告名称、本地列、引用表、引用列与两个动作。
- [ ] 复合外键的本地列与引用列**按同一位置配对**（第二个本地列对应第二个引用列），不是按名或按集合。
- [ ] 索引报告列清单与唯一性；表达式列按"无名"处理（与另两种引擎一致）。
- [ ] **主键背后的索引不出现在索引清单里**。
- [ ] 表/视图注释与列注释如实报告（无注释则为空）。
- [ ] 描述视图只给列，键/外键/索引为空。
- [ ] 契约套件中这些断言在 PostgreSQL 上通过；**视图列 nullability 在 PG 不传播**这一真实分歧留在引擎专属测试并记录。
